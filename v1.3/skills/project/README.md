# project/

Whole-project assessment and mapping skills — for understanding or evaluating an entire
codebase rather than working on a specific change.

| Skill | Use When |
|-------|----------|
| [`senior-fullstack-audit`](./senior-fullstack-audit/SKILL.md) | Full project audit, health check, codebase assessment — 20-area scorecard with prioritized action items |
| [`project-sitemap`](./project-sitemap/SKILL.md) | Codebase structure mapping, architecture overview, AI/developer onboarding |

When an audit surfaces a concrete bug, hand off to `engineering/bug-debugging`. When
the audience for the summary is leadership / PM, hand off to
`communication/management-talk`.
