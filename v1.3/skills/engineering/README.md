# engineering/

Domain skills for code work. The largest bucket — pick the most specific skill for the
task and combine with others when the work crosses domains.

| Skill | Use When |
|-------|----------|
| [`backend-architecture`](./backend-architecture/SKILL.md) | Backend features, API design, service layers, business logic |
| [`bug-debugging`](./bug-debugging/SKILL.md) | Any bug — includes Rigid 4-phase gate + recite-verbatim Debug Mantra |
| [`code-review-refactor`](./code-review-refactor/SKILL.md) | Checklist-based review — includes Simpler-Alternative pass (Step 0) |
| [`database-performance`](./database-performance/SKILL.md) | Schema review, query optimization, indexes, migrations |
| [`deployment-devops`](./deployment-devops/SKILL.md) | Production readiness, CI/CD, rollback, monitoring |
| [`frontend-ux-engineering`](./frontend-ux-engineering/SKILL.md) | UI/UX work, responsive design, accessibility, performance |
| [`git-workflow`](./git-workflow/SKILL.md) | Branching, commits, PRs, conflicts, releases |
| [`migration-upgrade`](./migration-upgrade/SKILL.md) | Framework upgrades, dependency updates, breaking changes |
| [`release-version`](./release-version/SKILL.md) | SemVer, changelog, tagging, release notes |
| [`remove-color-transition`](./remove-color-transition/SKILL.md) | Remove color transitions while preserving motion |
| [`remove-shadow-utilities`](./remove-shadow-utilities/SKILL.md) | Remove shadows while preserving rings / outlines / focus |
| [`scrutinize`](./scrutinize/SKILL.md) | Outsider-stance second opinion — pairs with `code-review-refactor` |
| [`security-hardening`](./security-hardening/SKILL.md) | Security review, vulnerability fixing |
| [`shadcn-reinstall`](./shadcn-reinstall/SKILL.md) | Safe shadcn/ui reset and reinstall |
| [`testing-qa`](./testing-qa/SKILL.md) | Tests, QA checklists, coverage, regression |
