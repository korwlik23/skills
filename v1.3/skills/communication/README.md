# communication/

Written artifacts — for engineers, for leadership, for external audiences. Different
skill per audience and channel.

| Skill | Use When |
|-------|----------|
| [`post-mortem`](./post-mortem/SKILL.md) | After a non-trivial bug is fixed and validated — engineer-to-engineer RCA. Refuses to draft without all four required inputs. |
| [`management-talk`](./management-talk/SKILL.md) | Rewrite engineering content for leadership / PM, shaped per channel (ticket / Slack / standup / email / talking-points). |
| [`project-documentation`](./project-documentation/SKILL.md) | README, installation guides, architecture docs, feature lists, usage guides |
| [`project-job-description`](./project-job-description/SKILL.md) | Resume, portfolio, job description, or skill assessment from codebase evidence |

The natural pipeline is `post-mortem` → `management-talk`: post-mortem owns the
engineering truth, management-talk reframes it for the channel.
